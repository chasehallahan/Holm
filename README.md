# Hólm

**Hólm** is a multiplayer Viking combat sandbox focused on grounded melee combat, social play, and emergent chaos.

Set in a historically inspired Norse world, players gather, fight, duel, and experiment with weapons and movement systems in a shared space. The current focus is on **feel-first melee mechanics** and **multiplayer hangout gameplay**, with longer-term plans for squad-based raids and extraction-style objectives.

## Current State
- Early prototype / sandbox
- Procedural, physics-driven melee combat
- Multiplayer-focused experimentation

## Vision
Hólm aims to blend:
- Weighty, skill-based melee combat
- Small to mid-scale squad encounters
- Historically grounded Viking themes

## Roadmap
- Core combat polish
- Player interaction systems
- Social hub mechanics
- Extraction-style objectives (long-term)
